RELEVANCE SCORING ANALYSIS & EVALUATION OVERVIEW
================================================

Project: RAG Laptop Shopping Assistant
Evaluation Method: Multi-Modal Retrieval Comparison (Dense vs BM25 vs Hybrid)
Date: September 26, 2025

WHAT WE CHECKED IN RELEVANCE SCORING
====================================

Our relevance scoring system evaluates how well each retrieval mode returns documents that match the query intent and content. The scoring is category-specific and context-aware:

1. EXACT PRODUCT QUERIES
   ----------------------
   What we check:
   - Brand name matching (e.g., "acer" in query → "acer" in document)
   - Specific model matching (e.g., "extensa" in query → "extensa" in document)
   - Price-related terms ("price", "$", "₹", "cost")
   
   Scoring system:
   - Brand match: +2 points per document
   - Model match: +2 points per document  
   - Price terms: +1 point per document
   - Maximum: 5 points per document

   Example: "Acer Extensa 15 price"
   - Document with "Acer Extensa" + price mention = 5 points
   - Document with just "Acer" = 2 points
   - Document with neither = fallback scoring only

2. BRAND QUERIES
   --------------
   What we check:
   - Primary brand mentions (HP, Dell, Acer, Lenovo, Asus)
   - Laptop context confirmation
   
   Scoring system:
   - Brand match: +3 points per document (heavily weighted)
   - Laptop mention: +1 point per document
   - Maximum: 4 points per document

3. SEMANTIC/CONCEPTUAL QUERIES
   ----------------------------
   What we check:
   - Context-specific terms:
     * "student" → "portable", "lightweight", "study", "education"
     * "gaming" → "gaming" (exact match)
     * "professional" → "business", "office", "work"
     * "affordable" → "budget", "cheap", "value"
   - Basic laptop relevance
   
   Scoring system:
   - Context match: +2 points per relevant term
   - Laptop mention: +1 point per document
   - Maximum: varies based on query complexity

4. KEYWORD-HEAVY TECHNICAL QUERIES
   --------------------------------
   What we check:
   - Technical specifications: "intel", "core", "i3", "i5", "i7"
   - Memory terms: "8gb", "16gb", "ram"
   - Storage terms: "ssd", "hdd"
   - Processor terms: "amd", "ryzen"
   - General laptop relevance
   
   Scoring system:
   - Each technical term match: +1 point
   - Laptop mention: +1 point
   - Cumulative scoring across all matching terms

5. OUT-OF-SCOPE QUERIES
   ---------------------
   What we check:
   - INVERSE scoring: Lower relevance is better
   - Laptop mentions = penalty (shows system returning wrong content)
   - Non-laptop content = reward (shows proper filtering)
   
   Scoring system:
   - Contains "laptop": 0 points (bad - wrong domain)
   - No laptop mentions: 3 points (good - proper rejection)
